# DevCommander OS Final Landing Page

Final landing page package.

## Included

- Next.js 15
- TypeScript
- Tailwind CSS
- Geist tech font
- Dark / light mode
- Runtime terminal animation
- Animated grid background
- Lucide real UI icons only
- Vercel-ready

## Run

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Build

```bash
npm run build
```

lib/site.ts
